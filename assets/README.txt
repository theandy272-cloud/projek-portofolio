Assets folder
=============

Place real assets here:

- Profile photo       → replace the gradient placeholder (.profile-card__photo
                        in css/sections.css) with an <img src="assets/profile.jpg">.
- Resume              → add "andi-wahyudi-resume.pdf" here. The hero
                        "Download Resume" button links to this file.
- avatar.svg          → included placeholder avatar / favicon.

Suggested image sizes:
- profile.jpg : 600 x 600 px, square, < 300 KB
- resume.pdf  : A4, 1-2 pages
